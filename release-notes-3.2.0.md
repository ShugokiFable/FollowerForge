# FollowerForge 3.2.0

**Windows tool:** build a full custom Skyrim SE/AE follower without the Creation Kit.

## Download

**`FollowerForge-3.2.0-win-x64.zip`**

Unzip anywhere → **FollowerForge.exe**. Self-contained.

## Highlights

- **Mod Organizer 2** support alongside Vortex (instance discovery, modlist priority, private hardlink plugin view — does not write into game Data or your mods tree).
- **SHARE-CHECKLIST.txt** on every build; **RSVexclude.ini** when own-hub / author texture prefixes apply.
- Clearer face language: missing export/jslot vs **NO SCULPT** (slider-only) vs no tint; optional SavePCFace noted.
- **SMP hair** documented honestly (HDPT ok; physics need FSMP on the player side).
- Nexus description rewritten: character depth first (voices, dialogue, creatures, placement).
